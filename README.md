## 🚀 Featured Projects

### 📱 [Safco eCredit](https://play.google.com/store/apps/details?id=com.vergesystems.safco_e_banking) — Live on Google Play, 5,000+ downloads
Loan-servicing app for Safco Support Foundation clients — approved loan amounts, repayment schedules, and loan history, with offline-capable local storage.
`React Native CLI` `SQLite` `Redux Toolkit`

### 🏥 [QueueLess](https://github.com/Awais-Chandio/QueueLess) — Real-Time Clinic Queue Management
Replaces physical waiting rooms with real-time slot booking and live queue status. Three-role architecture (Client/Staff/Admin) secured with Supabase Row-Level Security and custom JWT claims via a Custom Access Token Hook.
`React Native CLI` `Supabase` `Row-Level Security`

### 🍔 [FoodApp](https://github.com/Awais-Chandio/FoodApp) — Role-Based Food Ordering
Two-role architecture (Admin/Customer) with offline-capable order and menu management, plus a dedicated admin panel for product and order control.
`React Native CLI` `SQLite` `Role-Based Access`
